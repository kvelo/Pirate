# Zone 101 — donnees du graphe

Le modele est centralise dans `PLC/POU/FB_Zone.st` (57 noeuds, 80 equipements, 80 aretes).
`PLC/POU/FB_BFS.st` calcule l'alimentation des noeuds.

Voir `ZONE101.md` et `zone101_correspondances.csv` pour la numerotation et les reperes.
La simulation est independante des anciens objets postes/ports et aucun mapping automatique PIRATE n'est active.
